Error Handling in Famous Engine

The Famous Engine provides a comprehensive error handling system with typed errors, error codes, suggestions, and validation utilities.

Validation Utilities

requireParameter(value, name)

Ensures a parameter is not null or undefined.

requireType(value, name, expectedType)

Validates that a parameter is of the expected type.

Typed Errors

ParameterError

Thrown when a parameter has an invalid value.

InitializationError

Thrown when engine initialization fails.

Catching FamousError

All Famous errors inherit from FamousError for easy catching.
